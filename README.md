# TQQQ on Real Prices

A static research page: a backtest report on TQQQ strategies, with a period tool that replays each book from any start month, start sum, yearly sum and tax rate.

This repository holds only the built page (`index.html`), the period tool's data files (`tq/`, `tq9/`, `tq94/`, `tq98/`, `tq104/`, and `tqx/`, which runs every book on from 30 Oct to 20 Nov 2026, after the study's read), the call books' runs from Feb 2010 with no limit on a call (`tqn/`), and the trades behind its chart's dots (`tqt/`). It is generated; nothing here is edited by hand. Facts from backtests, not advice.
