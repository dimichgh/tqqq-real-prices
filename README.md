# TQQQ on Real Prices

A static research page: a backtest report on TQQQ strategies, with a period tool that replays each book from any start month, start sum, yearly sum and tax rate.

This repository holds only the built page (`index.html`) and the period tool's data files (`tq/`, `tq9/`, `tq94/`). It is generated; nothing here is edited by hand. Facts from backtests, not advice.
